# Openboost v0.2.0

Deployment and OCMOD lifecycle release.

## Highlights

- Adds a reusable Git-to-OpenCart deployment architecture.
- Adds a local incremental deploy agent with backups, health checks and deployment state.
- Adds a signed PHP server bridge for privileged OCMOD/cache actions.
- Adds an OpenCart 2.3 OCMOD full-refresh adapter.
- Standardizes OCMOD identity: stable canonical `<code>`, changing release number in `<version>`/package/tag.
- Adds explicit legacy versioned-code cleanup rules instead of fuzzy OCMOD deletion.
- Adds replay-protected HMAC bridge authentication and explicit cache profiles.
- Routes deployment tasks automatically to the new `opencart-deployment` skill.

This release builds on v0.1.0's project analysis, architecture map, module development, i18n, OCMOD, UI/UX and GitHub workflow standards.

See `CHANGELOG.md` for the complete release history.
